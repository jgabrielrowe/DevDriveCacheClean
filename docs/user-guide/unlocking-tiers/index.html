Unlocking costly and destructive items

DDCC sorts Caches results into three tiers. The tier tells you how cautious to be and controls how the row can be selected.

Safe items can be selected in bulk with the Tier 1 button. These are usually local build output or app caches that can be rebuilt from files already on your Mac.

Costly items can be selected after you enable their category for the current scan. Turning on Tier 2 lists the locked categories currently in view, along with their item counts and sizes. Enabling a costly category does not persist after a new scan.

Destructive items are never selected in bulk. Click a destructive row to review it, then opt in to that one item if you want to select it.

Shown but never removed items use disk space but cannot be selected. These are usually root-owned or protected paths.

See The three tiers for the full tier descriptions.
