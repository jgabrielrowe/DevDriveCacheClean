§ 08DDCC/User Guide/Moving files to the Trash

Moving files to the Trash

The Files view only moves items to the Trash. It does not offer permanent deletion.

Files results are broad discoveries, not categorized cache results. A large old file might be disposable, or it might be the only copy of something important. Review each selected item before moving it.

Before moving files, DDCC shows a confirmation sheet with every selected path and the total size. After the move, the files are in the macOS Trash and can be put back from Finder.

If a file cannot be moved, it stays in the list, remains selected, and DDCC shows the reason at the bottom of the window.
