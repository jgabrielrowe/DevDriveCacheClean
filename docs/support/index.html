DDCC/Support the project

This is free, and it always will be.

You never need to pay to use DDCC. There is no trial, licence key, or feature tier. If you want to support development or just say thanks, that is appreciated and never expected. Bug reports and cache patterns help just as much.

£0forever
  • No paid tier
  • No feature behind a wall
  • No expiry

The most useful things are free.

A good bug report is worth more than a coffee, and a cache pattern DDCC does not yet recognise is worth more than either. Both belong on the issue tracker, where the answer stays public and the next person with the same folder can find it. Email support@devdrivecacheclean.com instead if you would rather not use GitHub.

01

Tell me what it missed

A folder eating gigabytes that DDCC did not recognise is the single most valuable thing you can send. Include the path and the tool that made it.

02

Tell me when a number looked wrong

If a total did not match what you actually got back, that is a defect in the one thing this app claims to do well.

03

Report anything that felt unsafe

A confirmation that was unclear, an action that surprised you, a row you could not understand. All of it counts.

04

Tell one person

There is no marketing budget here and no advertising. Word of mouth is the entire distribution plan.

And if you would like to chip in.

Your support is appreciated. One-time donations only. There is no subscription to cancel, and the app behaves the same either way.
