Bugs, and caches DDCC does not recognise

The issue tracker is the place for both. The answer stays public there, so the next person with the same folder finds it rather than asking again. A path, the tool that wrote it, and what you expected DDCC to say about it is enough to open with.

Security

Report it privately. The security page gives the private channel, the subject line to use if you would rather email, and what good-faith research means here.

Privacy, terms and licensing

Email is right for these. What the site records, the terms and the licence are each written out in full, so the pages themselves may answer it faster than I can.

What to expect

This is a one-person project, so there is no team on call and no guaranteed response window. Mail is read and answered as soon as I see it.

DDCC

DevDriveCacheClean is free, and always will be. You never need to pay to use it. If you'd like to support development, that's appreciated, but never required.
