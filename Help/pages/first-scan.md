# Your first scan

Press **Scan**. DDCC searches your home directory by default; the folder menu
beside the button changes where it looks.

When the scan finishes you will see categories in the sidebar and individual
items in the list. The sidebar shows totals by category. The list shows each
path, size, category, tier, and modification date.

If a total or row size ends with `+`, DDCC could not read everything needed for
an exact number. Treat that value as at least that large, not as the full size.

Nothing is selected when a scan finishes. Use **Tier 1** to select safe items
in the current view. Use **Tier 2** to review and enable costly categories for
this scan. Destructive items must be selected one at a time.

Use the search field to filter results. A filter can hide selected items; if
that happens, the delete confirmation still lists the hidden selection before
anything is removed.

The toolbar shows how many items are selected and how much space they use. When
you press **Delete**, DDCC lists the selected paths and asks you to confirm.
See [Choosing what to remove](choosing-what-to-remove.html) for the toolbar,
sort, and sidebar controls.

Selections do not survive a new scan. Each scan starts from nothing selected,
so old choices are not applied to new results.

If a scan is stopped, DDCC keeps completed Caches results on screen and marks
the total as incomplete. Run the scan again when you need a complete current
answer.
