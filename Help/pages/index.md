# DDCC Help

DDCC helps you find developer caches, build output, large files, and what an
uninstalled app left behind, then remove only what you choose.

If you are new to the app, start with [What DDCC does](what-ddcc-does.html),
then [Your first scan](first-scan.html). Use the reference pages when you want
details about a category, tier, or control.
