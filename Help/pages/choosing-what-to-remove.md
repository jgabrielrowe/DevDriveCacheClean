# Choosing what to remove

Use the Caches toolbar to scan, filter, sort, select, and delete results.

**Scan** searches the selected folder. **Scan Path** changes that folder; the
default is your home directory. **Stop** cancels an active Caches scan. Results
already completed by the scan may remain on screen, but you should scan again
when you want a complete current result set.

The search field filters the visible rows. The sort picker changes the list
order: largest first, smallest first, name, or oldest first.

The sidebar filters by result group. **Caches** shows everything from the last
scan. Category rows show that category's total size and item count. If a row
says part of the total is locked, DDCC can show that space but cannot select
those items because macOS or the current permissions prevent removal.

Use **Tier 1** to select all safe items currently in view. Use **Tier 2** to
review and enable costly categories currently in view. Enabling a Tier 2
category lasts only for the current scan. Destructive items are selected only
by clicking individual rows.

**Deselect All** clears the whole selection, including selected rows hidden by
the current search or sidebar filter.

**Delete** appears after you select at least one item. It opens a confirmation
sheet; it does not remove anything immediately.

The Files view works differently: **Stop** discards the in-progress Files
search, Files has no select-all, and selected files can only be moved to the
Trash.
