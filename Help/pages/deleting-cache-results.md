# Deleting cache results

Press **Delete** after selecting Caches results. DDCC opens a confirmation sheet
before removing anything.

The confirmation sheet lists selected items by tier. If your current filter is
hiding selected items, those hidden items appear in a separate section so you
can review everything that will be removed.

By default, DDCC moves selected items to the Trash. Leave this default on when
you are not sure, or when you want an easy way to put files back.

You can choose **Permanently delete** in the confirmation sheet. This skips the
Trash and cannot be undone. That choice is a checkbox and nothing more.

Only tier 3, the destructive tier, asks for more than a checkbox. If the
selection includes any destructive item, DDCC requires you to type `DELETE`
before the button is enabled — whether you are moving those items to the Trash
or deleting them permanently. Tiers 1 and 2 never ask for this.

The Files view does not have this permanent-delete option. Files results are
not classified cache results, so DDCC only moves them to the Trash.

If an item cannot be removed, DDCC leaves it in the results and records the
failure reason at the bottom of the window. Failed items stay selected so you
can retry or inspect them. A failed item is not counted as reclaimed space.
